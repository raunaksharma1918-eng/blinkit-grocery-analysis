# BlinkIT Grocery Data Analysis

Analysis of 8,523 BlinkIT grocery records using Python, pandas and PostgreSQL.

## Tools
Python, pandas, SQLAlchemy, PostgreSQL, Jupyter Notebook

## Key Insights
- Top item type by sales: Fruits and Vegetables
- Best outlet type: Supermarket Type1
- Best location tier: Tier 3
- Average rating: 3.97

## Files
- BlinkIT_Grocery_Analysis.ipynb: analysis notebook
- queries.sql: SQL queries
